# 变更提案：卒中康复训练 MVP

## 背景

本变更为单个患者自用的卒中康复训练应用提供最小可用闭环。患者通过移动端 H5 记录训练，操作者通过 LinaPro 管理后台维护图片卡和查看训练记录。

## 目标

- 提供患者 H5：慢走、握拳平举、眼睛凝视、图片卡辨物、历史汇总。
- 通过 IndexedDB 实现本地优先记录，网络可用后同步至后端。
- 新增 LinaPro 源码插件 `rehab-cards` 管理图卡分类、图卡和占位爬取任务。
- 新增 LinaPro 源码插件 `rehab-records` 存储训练记录并提供按日聚合。
- 提供本地 Docker Compose 服务栈：PostgreSQL、LinaPro、H5 nginx。

## 非目标

- 不提供医生端、家属端或多患者管理。
- 不在 MVP 中实现真实外部图片 API 抓取，仅提供占位生成流程。
- 不在 MVP 中实现手机号绑定；后续由设备配对账号迁移到正式认证方案。
