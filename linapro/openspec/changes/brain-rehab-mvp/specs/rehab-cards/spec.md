# 规范：康复图卡管理

## ADDED Requirements

### Requirement: 图卡分类与卡片管理

系统应通过 LinaPro 管理后台提供图卡分类和图片卡片的基础管理能力，用于支持患者端图片卡辨物游戏。

#### Scenario: 管理分类

- **Given** 操作者已登录 LinaPro 管理后台
- **When** 操作者新增、编辑或删除图卡分类
- **Then** 后端应持久化分类变更，并在分类列表中展示最新结果

#### Scenario: 管理图片卡片

- **Given** 已存在至少一个图卡分类
- **When** 操作者新增、编辑或删除图片卡片
- **Then** 后端应持久化卡片变更，并供患者 H5 查询启用卡片

### Requirement: 占位爬取任务

系统应提供按分类和关键词生成占位图卡的管理入口，后续可替换为真实外部图片 API 抓取。
