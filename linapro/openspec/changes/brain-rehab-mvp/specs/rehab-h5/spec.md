# 规范：患者 H5

## ADDED Requirements

### Requirement: 患者端训练记录

系统应提供患者自用 H5 页面，用于记录慢走训练时长、握拳平举组数和次数、眼睛凝视次数、图片卡辨物结果以及本地历史汇总。

#### Scenario: 离线记录训练

- **Given** 患者设备暂时无法访问后端
- **When** 患者保存训练记录
- **Then** 记录应先保存到 IndexedDB，并标记为待同步

#### Scenario: 本机配对后同步

- **Given** H5 已保存本机配对凭据
- **When** 网络可用且存在待同步记录
- **Then** H5 应调用后端训练记录接口并更新本地同步状态
