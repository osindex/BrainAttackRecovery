# 规范：康复训练记录

## ADDED Requirements

### Requirement: 训练记录存储

系统应存储患者 H5 同步的训练记录，包含慢走、握拳平举、眼睛凝视和图片卡辨物四类训练。

#### Scenario: 幂等同步记录

- **Given** H5 使用相同 `clientRecordId` 重试上传同一条训练记录
- **When** 后端已存在该记录
- **Then** 后端应返回已有记录 ID，而不是创建重复记录或让客户端永久同步失败

### Requirement: 按日聚合

系统应提供按日期和训练类型聚合的接口，用于后台和 H5 展示训练趋势。
