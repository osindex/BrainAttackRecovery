# Patient H5

Mobile-first H5 application for single-patient stroke rehabilitation training.

## Features

- Walking timer
- Fist-raise sets and reps counter
- Eye-gaze left-right counter
- Illustrated instructions, safety tips, and speech playback for physical exercises
- Picture-card naming game
- Local history summary
- IndexedDB-first persistence with backend sync after device pairing

## Commands

```bash
pnpm install
pnpm dev
pnpm build
```

## Pairing

The app does not include default LinaPro credentials. Open **本机配对** in the H5 app and enter a low-privilege LinaPro account created for this patient device.
